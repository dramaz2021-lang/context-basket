# 开发顺序

用户已调整顺序：先体验拖入浮窗，再决定后续交付方式。

## 当前：0.1 拖入 UI

- [x] 原生可构建应用和本地打包。
- [x] 圆角半透明置顶浮窗。
- [x] 拖入文字、链接、图片和文件。
- [x] 每份材料独立预览，鼠标移入显示右上角删除叉号。
- [x] 多项材料、滚动、计数和拖入高亮。
- [x] 放大预览、手动粘贴、选文件和删除撤销。
- [x] 本机保存和恢复。
- [x] 完成真实窗口的拖入、预览、删除撤销和恢复验证，详见验证记录。
- [ ] 在用户实际鼠标操作下确认持续悬停外观，收集首轮体验反馈。

## 下一步：根据 UI 试用反馈调整

重点关注浮窗大小、卡片密度、文字可读性、删除叉号、拖入反馈，以及窗口是否遮挡工作。

## 后续：自动采集

剪贴板监听、系统截图目录监听、采集启停和去重，作为后续独立任务。

## 后续：交付给 Agent

使用少量合成材料验证 ChatGPT 各入口的整组拖入方式。根据实际限制决定必要的格式转换，保留原文和原图。此项不是当前 UI 的前置验收条件。

## 正式分发前

完善资产回收、持久化迁移、旧系统兼容性、签名公证和安装包。

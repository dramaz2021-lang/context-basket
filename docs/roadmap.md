# 开发顺序

## 0.11 液态玻璃与双列气泡

- 顶栏增加剪贴板暂停/继续、清空全部内容（可撤销）。
- 指令从一行开始，按实际排版自动增高；附件每行两个，空位显示“+”。
- 副本/链接色块仅在文件拖入当前空位时显示。
- 原生 Liquid Glass 与旧系统材质回退。

## 0.10 气泡界面

- 默认图标，点击后按草图展开：顶栏图标/预览/复制，第二排指令输入，下面是附件与添加入口。
- 附件单列，大“+”添加气泡始终在列表末尾，绿/蓝色块选择副本或链接。
- 沿用完整 Prompt 与附件复制、自动收集、说明与预览。

## 0.9 一次复制 Prompt 与附件

- 有附件时同时交付 PROMPT.txt 和副本附件，适配浏览器粘贴文件时不提供普通文字的行为。
- 纯文字场景直接复制文字；副本快照在删除材料后仍可读取。
- 底部预览与复制同样高亮；撤销移到顶部“+”旁，添加链接只留在“+”菜单。

## 0.8 精简 Prompt 与点击展开

- 任务与附件说明组成完整 Prompt，副本不含路径、类型或使用约定。
- 内容变化时自动更新，左侧预览、右侧复制，不显示生成成功提示。
- 附件说明 Return 完成，Shift+Return 换行。
- 悬浮图标点击展开，左上图标或右上按钮手动收起，取消自动收起；拖文件仍展开。

## 0.7 生成并复制完整 Prompt（已由 0.8 简化）

- 主按钮改为生成并复制，去 Agent 中粘贴即可。
- 固定结构组织任务、编号材料和说明，文字原样内嵌，图片与文件提供本机路径。
- 副本路径使用独立快照，预览与复制复用相同生成结果。

## 0.6 自动收集剪贴板与精简顶部操作

- 产品名称统一为 context basket，操作合并到“+”菜单。
- 默认自动添加新复制的内容，本机文件始终作为副本；提供持久化开关。
- 不补收旧剪贴板、不重复处理同次变化、不回收本应用复制的 Prompt。
- 新增剪贴板自动收集、开关、数据兼容与副本语义检查，验证结果见兼容性记录。

## 已完成：0.5 点击预览与明确的拖入范围

- 悬停只显示说明和删除，直接点击卡片打开预览。
- 源地址定位原文件并打开系统快速预览；网页链接打开原网址。
- 文件和图片拖到指令框完全忽略，材料只能拖入上方上下文区；正常文字编辑和撤销保留。
- 28 项自动检查通过，实际窗口验证原件定位、系统预览、副本预览及指令框拒收附件。

## 已完成：0.4 直接选择拖入方式

- 文件拖入材料区显示绿色“副本”和蓝色“链接”两个大色块，按落点决定本次方式。
- 指令框保持纯文字；图片、文件拖入后转为上下文材料，不显示方式选择。
- 文字拖入和撤销保持正常，后续仍可更改材料的副本/引用方式。
- 25 项自动检查通过，真实窗口已验证左右文件落点、图片/文件拖入指令框、文字拖入和撤销。

## 已完成：0.3 透明浮窗与自动收起

- 去除接近实心的底色和毛玻璃叠层，保留真实半透明背景。
- 移出收为图标，悬停展开，数量徽标和拖入展开。
- 防止短暂跨过窗口边缘导致闪烁，编辑、菜单与拖拽期间暂缓收起。
- 自动收起状态逻辑增加 5 项验证，全部数据行为检查共 20 项。

## 已完成：0.2 Prompt 编辑原型

- 原生可构建置顶浮窗，逐项拖入和预览。
- 悬停说明、预览、删除操作，删除撤销。
- 副本 / 源地址模式，逐项说明，底部任务指令。
- 说明和指令本机保存，兼容 0.1 列表。
- 半透明拖出和窗口移动。
- 完整 Prompt 预览、复制文字、整组快照拖出。
- 合成材料原生接收端验证指令、说明、附件和引用语义。

## 下一步：粘贴后的使用体验

按实际使用反馈检查 Prompt 可读性及附件说明。主流程已改为复制粘贴，不继续进行 TXT/MD 多文件拖拽比较。

持续悬停外观、真实鼠标的拖动透明度还需用户试用反馈；自动化工具无法稳定停留光标或截取拖动中间帧。

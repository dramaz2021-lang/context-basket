## 测试方法

1. 使用 Tests/Fixtures 中的合成材料，记录应用提交、系统、浏览器或客户端版本以及相关账户条件。
2. 收集 3 段文字和 3 张有明确编号的图片；至少一张图包含只能从图中获取的信息。
3. 一次拖出 `context.txt` 和 3 张图片，检查附件数量和内容。
4. 等待目标端实际完成上传，再提出需要综合图文的问题。
5. 检查原文细节、视觉信息及文件对应关系；记录遗漏和误配。
6. 分别验证取消、重复拖出、目标端拒收，以及拖出后新增材料。
7. 检查拖拽结束后目标端是否延迟读文件，据此制定导出文件保留策略。

结果必须区分：系统接受拖拽、附件出现在输入框、上传完成、模型正确使用材料。

文件数量、大小、格式的边界另行实测记录，不凭单次成功宣称普遍兼容。截图或录像只使用合成材料，避免记录个人对话和账户信息。

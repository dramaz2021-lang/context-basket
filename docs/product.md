# 产品范围：Prompt 编辑浮窗

把材料和任务指令放在同一个可编辑区域，允许用户反复整理，完整 Prompt 随内容自动更新，随时预览并复制到 Agent。

| 操作 | 结果 |
| --- | --- |
| 在其他应用复制文字、图片、网址或文件 | 默认自动添加到材料区；本机文件始终复制，文字原样保留 |
| 顶栏剪贴板暂停/继续按钮 | 暂停/恢复，重启后保留选择；恢复时只收集之后新复制的内容 |
| 鼠标离开 | 保持当前展开/收起状态 |
| 鼠标移入图标 | 保持收起 |
| 启动 | 只显示带材料计数的图标 |
| 点击图标 | 展开顶栏（图标、预览、复制、剪贴板暂停/继续、清空）、第二排单行起步的指令输入、下方双列附件区 |
| 拖文件到图标 | 展开并继续接收拖入内容 |
| 再次点击图标 | 缩为悬浮图标，保留全部内容 |
| 添加材料 | 附件按顺序每行两项，剩余空位为大“+”，填满一行后再添一行 |
| 鼠标悬停卡片 | 说明和删除两个按钮 |
| 点击副本或文字卡片 | 直接打开材料预览 |
| 点击源文件地址卡片 | 在 Finder 定位原文件，并用系统快速预览打开 |
| 点击网页链接卡片 | 打开原网址 |
| 添加文件说明 | 深蓝文字、浅蓝底及成对引号展示；直接编辑用途或修改重点；Return 完成，Shift+Return 换行 |
| 拖文件到添加气泡绿色色块 | 本次添加独立副本，修改附件不影响原件 |
| 拖文件到添加气泡蓝色色块 | 本次引用本机源路径；不导出原件附件 |
| 图片、文件拖到指令框 | 直接忽略，不显示接收提示、不增加材料、不修改指令 |
| 文字、网页链接拖到指令框 | 以纯文字插入指令，可撤销 |
| 没有源地址的图片拖到材料区 | 直接收集为副本，不提供无效的本机链接选项 |
| 右键有来源的文件 | 在副本和源地址之间切换，保留说明 |
| 添加链接或本机地址 | 网页链接保留 URL，本机路径作为源地址 |
| 第二排指令输入 | 编辑任务，默认一行；换行/折行自动增高，长内容滚动 |
| 复制完整 Prompt（顶栏） | 有附件时一次复制 PROMPT.txt 和全部附件副本；只有文字时直接复制文字，无生成步骤或成功提示 |
| 拖出单张卡片 | 该材料及其说明，不包含整组任务指令 |
| 文件副本 | Prompt 中只列附件名称与说明，不显示路径或类型，不加使用约定 |
| 预览完整 Prompt（顶栏） | 查看当前完整文字，随材料、任务和说明变化实时更新 |
| 删除、撤销 | 只移除收集项，不影响源文件；撤销按钮在大“+”旁及菜单内，无可撤销项时不显示气泡按钮 |
| 顶栏“×” | 清空当前全部附件、附件说明和指令；应用保持运行，可一步撤销 |
| 重启 | 恢复材料、说明、指令和导入方式 |

收起为 58 点图标，展开宽 460 点。指令框默认高 44 点，按内容增高，最高 188 点后滚动。附件为双列，编辑说明时整行增高；内容超过屏幕高度后滚动。每个气泡内部独立绘制无色玻璃；不使用连接气泡的共用材质、彩色高光或外扩光晕。macOS 26+ 使用原生 Liquid Glass，旧系统回退透明材质。拖动图标移动整组气泡。

不自动推断文件用途、不修改用户指令、不调用模型。源地址是否可读取决于 Agent 的本机访问能力；副本通过系统剪贴板的文件列表交付，是否接收及上传由目标应用处理。

拖拽仅按当前落点选择模式，不依赖此前默认值或 Option 键。选文件/主动粘贴的默认方式保留在“+”菜单；已有材料仍可右键转换。

空态展示两个大“+”，保留“把材料拖到这里”“图片、文字、链接、文件”提示；指令为空时显示“输入指令”。本机文件拖入某个添加位时才显示该位置的副本/链接色块。预览与复制按钮采用相同高亮样式，“+”菜单承载其他添加与设置。自动收集在浮窗折叠或隐藏时继续运行；每次剪贴板变化只处理一次，不补收启动前的内容，不回收本应用“复制完整 Prompt”产生的 Prompt，也不收集带机密、临时或自动生成标记的内容。网页链接只保留网址，不下载网页。

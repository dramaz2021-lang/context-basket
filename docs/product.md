# 产品范围：Prompt 编辑浮窗

把材料和任务指令放在同一个可编辑区域，允许用户反复整理，完整 Prompt 随内容自动更新，随时预览并复制到 Agent。

| 操作 | 结果 |
| --- | --- |
| 在其他应用复制文字、图片、网址或文件 | 默认自动添加到材料区；本机文件始终复制，文字原样保留 |
| “+”菜单的自动收集开关 | 暂停/恢复，重启后保留选择；恢复时只收集之后新复制的内容 |
| 鼠标离开 | 保持当前展开/收起状态 |
| 鼠标移入图标 | 保持收起 |
| 点击图标 | 展开，仍在置顶层 |
| 拖文件到图标 | 展开并继续接收拖入内容 |
| 点击展开后的左上图标或右上收起按钮 | 缩为悬浮图标，保留全部内容 |
| 拖入材料 | 每项独立显示，图片缩略图、文字片段、链接或文件图标 |
| 鼠标悬停卡片 | 说明和删除两个按钮 |
| 点击副本或文字卡片 | 直接打开材料预览 |
| 点击源文件地址卡片 | 在 Finder 定位原文件，并用系统快速预览打开 |
| 点击网页链接卡片 | 打开原网址 |
| 添加文件说明 | 直接编辑用途或修改重点；Return 完成，Shift+Return 换行 |
| 文件拖到材料区左侧绿色色块 | 本次添加独立副本，修改附件不影响原件 |
| 文件拖到材料区右侧蓝色色块 | 本次引用本机源路径；不导出原件附件 |
| 图片、文件拖到指令框 | 直接忽略，不显示接收提示、不增加材料、不修改指令 |
| 文字、网页链接拖到指令框 | 以纯文字插入指令，可撤销 |
| 没有源地址的图片拖到材料区 | 直接收集为副本，不提供无效的本机链接选项 |
| 右键有来源的文件 | 在副本和源地址之间切换，保留说明 |
| 添加链接或本机地址 | 网页链接保留 URL，本机路径作为源地址 |
| 底部指令输入框 | 编辑任务，可随材料变化而修改 |
| 复制完整 Prompt（底部右侧） | 有附件时一次复制 PROMPT.txt 和全部附件副本；只有文字时直接复制文字，无生成步骤或成功提示 |
| 拖出单张卡片 | 该材料及其说明，不包含整组任务指令 |
| 文件副本 | Prompt 中只列附件名称与说明，不显示路径或类型，不加使用约定 |
| 预览完整 Prompt（底部左侧） | 查看当前完整文字，随材料、任务和说明变化实时更新 |
| 删除、撤销 | 只移除收集项，不影响源文件；撤销按钮在顶部“+”旁，无可撤销项时置灰 |
| 重启 | 恢复材料、说明、指令和导入方式 |

展开为 460 点宽、两列预览和底部编辑区，收起为 58 点图标。底色只有 56% 不透明度，无实心毛玻璃叠层；文字和图片保持各自正常清晰度。拖出显示一个半透明小标签，移动浮窗时整体变淡。

不自动推断文件用途、不修改用户指令、不调用模型。源地址是否可读取决于 Agent 的本机访问能力；副本通过系统剪贴板的文件列表交付，是否接收及上传由目标应用处理。

拖拽仅按当前落点选择模式，不依赖此前默认值或 Option 键。选文件/主动粘贴的默认方式保留在“+”菜单；已有材料仍可右键转换。

主窗口仅保留空状态的拖入说明，移除收集提示、指令区标题及占位提示。材料内容、操作标签和错误信息保留。底部预览与复制按钮采用相同的高亮样式。产品名称统一为 context basket，顶部“+”承载添加与设置，添加链接只在菜单内，不再显示单独的“…”或链接按钮。自动收集在浮窗折叠或隐藏时继续运行；每次剪贴板变化只处理一次，不补收启动前的内容，不回收本应用“复制完整 Prompt”产生的 Prompt，也不收集带机密、临时或自动生成标记的内容。网页链接只保留网址，不下载网页。

# 产品范围：Prompt 编辑浮窗

把材料和任务指令放在同一个可编辑区域，允许用户反复整理，最后一起交付给 Agent。

| 操作 | 结果 |
| --- | --- |
| 鼠标离开 | 约半秒后缩为带材料数量的悬浮图标 |
| 鼠标移入图标 | 稍作停留后展开，仍在置顶层 |
| 拖文件到图标 | 展开并继续接收拖入内容 |
| 正在打字、组词或使用菜单 | 暂缓收起；仅焦点留在输入框时仍可自动收起 |
| 拖入材料 | 每项独立显示，图片缩略图、文字片段、链接或文件图标 |
| 鼠标悬停卡片 | 说明、预览、删除三个按钮 |
| 添加文件说明 | 直接编辑用途或修改重点，收起后显示引用文字 |
| 顶部选择复制副本 | 后续文件保存独立副本，修改附件不影响原件 |
| 顶部选择源文件地址 | 保存源路径，附说明；不导出原件附件 |
| 按住 Option 拖入 | 本次使用源地址模式 |
| 右键有来源的文件 | 在副本和源地址之间切换，保留说明 |
| 添加链接或本机地址 | 网页链接保留 URL，本机路径作为源地址 |
| 底部指令输入框 | 编辑任务，可随材料变化而修改 |
| 拖出全部 | PROMPT.txt + 编号副本附件，引用只写入路径 |
| 拖出单张卡片 | 该材料及其说明，不包含整组任务指令 |
| 复制文字 | 复制完整文字；副本附件仍需拖出 |
| 点击拖出全部 / 预览 | 查看将要交付的完整 Prompt |
| 删除、撤销 | 只移除收集项，不影响源文件 |
| 重启 | 恢复材料、说明、指令和导入方式 |

展开为 460 点宽、两列预览和底部编辑区，收起为 58 点图标。底色只有 56% 不透明度，无实心毛玻璃叠层；文字和图片保持各自正常清晰度。拖出显示一个半透明小标签，移动浮窗时整体变淡。

不自动推断文件用途、不修改用户指令、不调用模型。源地址是否可读取决于 Agent 的本机访问能力；接收端是否读取指令文件需要分别实测。

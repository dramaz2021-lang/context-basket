# 当前产品范围：先做好收集浮窗

## 目标

用户跨应用拖入材料，在浮窗里实时看到所有已添加内容，方便检查和移除。设计参考 Dropover 的轻巧悬浮、圆角和收纳感；材料始终逐项显示。

## 已实现交互

| 操作 | 结果 |
| --- | --- |
| 打开应用 | 出现始终置顶的收集浮窗 |
| 拖入材料 | 每项立即出现卡片，耗时导入显示加载状态 |
| 拖入多个文件 | 分别显示，按本次拖拽提供的顺序排列 |
| 拖到浮窗上方 | 整个窗口高亮，提示松开即可添加 |
| 鼠标移入卡片 | 右上角显示删除叉号 |
| 删除 | 从篮中移除，不删除用户原文件；允许一步撤销 |
| 点击卡片 | 查看完整文字或文件预览 |
| 添加较多材料 | 卡片网格滚动，自动显示新加入的材料 |
| 点击＋ / ⌘V | 选文件 / 主动粘贴 |
| 收起浮窗 | 菜单栏图标可重新打开 |
| 重启应用 | 恢复已保存的材料 |

## 视觉约定

420 点宽的深色半透明浮窗，两列卡片。图片显示真实缩略图，文字直接展示片段，链接保留网址，文件显示图标、文件名和大小。删除按钮叠在预览右上角，不遮挡整份材料。

## 后续再做

自动监听剪贴板、系统截图自动收集、整组拖给 Agent。无需先完成这些功能才能验收当前 UI。

当前材料原样保存，不做语义编排、自动摘要或模型调用。导出格式如需转换，在实际接收端验证后决定。

# Context Basket · 上下文篮

一个原生 macOS Prompt 编辑浮窗。跨应用收集材料，给每份材料加说明，边整理边写指令，最后整组拖给 Agent。

## 0.3 可运行原型

- 460 点宽、两列卡片的置顶浮窗，移除实心毛玻璃层，底色不透明度 56%，可直接透出后面的内容。
- 鼠标离开约 0.55 秒后收为 58 点悬浮图标；移到图标上约 0.16 秒后展开，图标显示材料数量。
- 持续打字、中文输入法组词、菜单、预览、选文件或拖拽期间暂缓收起；单纯输入框焦点不会固定展开。
- 文件拖到悬浮图标上会展开接收，展开与收起保留材料、说明、指令和滚动视图。
- 拖入图片、文字、网页链接、本机文件；每项立即显示预览。
- 悬停卡片出现说明、预览、删除按钮，右键菜单也能执行这些操作。
- 文件默认保存副本；顶部可改为“源文件地址”，按住 Option 拖入也可临时引用源地址。
- 通过顶部链接按钮直接输入网址或本机路径；卡片右键可在副本与源地址之间切换。
- 逐项保存用途说明，底部常驻指令编辑框，支持粘贴、撤销和重启恢复。
- “拖出全部”交付 PROMPT.txt 和副本附件；源文件引用只保留在文字里。单张卡片也能单独拖出。
- 拖出使用 48% 不透明度的小标签，移动浮窗时窗口变为 55% 不透明度。
- 点击“拖出全部”或左下角预览图标查看完整 Prompt；“复制文字”只复制文字，不携带副本附件。

导出只是按固定格式附上用户原话、材料说明、类型和路径，不做 AI 改写、摘要或语义编排。

## 试用

1. 把材料拖进浮窗，或点 ＋ 选择文件。
2. 需要修改原文件时，使用“源文件地址”模式，并在说明里写清楚修改重点。
3. 在底部编辑指令，点击预览检查完整内容。
4. 将“拖出全部”拖到接收文件的 Agent 输入区。

接收端需要支持多文件拖入并读取 PROMPT.txt。当前已验证 macOS 原生拖出交付，尚未逐个验证 ChatGPT、Claude、Codex 的接收行为。本机地址只有对能访问这台电脑文件的 Agent 才有用，不会授予新权限，也不会自动上传原文件。

## 构建

需要 macOS 14+ 和支持 Swift 6+ 的 Apple 开发工具。产物使用本机 CPU 架构。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open "dist/Context Basket.app"
```

使用本地临时签名，适用于本机试用。正式 Developer ID 签名、公证和跨机器分发尚未完成。

## 代码结构

```text
Sources/ContextBasketApp/
├── App/                  # 启动、菜单栏、浮窗生命周期
├── Features/Basket/      # 材料、用途说明、指令、卡片和预览
├── Platform/
│   ├── DragAndDrop/      # 导入、导出快照、半透明原生拖拽
│   ├── Windowing/        # 置顶窗口、文本编辑快捷键
│   └── Persistence/     # 副本、源地址、缩略图、版本化保存
└── Resources/
Tests/ContextBasketAppTests/
docs/
scripts/
```

一个应用目标，按职责分目录，不另建 Core 或插件框架。

## 使用边界

副本单个文件上限 100 MB；文件夹可作为源地址引用。网页图片提供文件承诺或图片数据时接收为副本；只有网址时保留链接，不主动下载。临时传输文件没有稳定源地址，因此始终保存副本。

材料、说明和指令保存在 Application Support/ContextBasket。0.1 列表会自动迁移；旧副本未记录来源，不能推测源地址，需重新拖入原文件。删除不会删除源文件；支持一步撤销。

每次拖出生成独立快照，即使之后继续编辑或删除，接收端仍能读取之前的文件。原型暂时保留这些本机导出缓存，尚未做自动回收。自动监听剪贴板和系统截图尚未实现。

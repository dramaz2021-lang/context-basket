# context basket

一个原生 macOS Prompt 编辑浮窗。收集材料，添加用途说明，写清任务，点击“复制完整 Prompt”，再到 Agent 中粘贴。

## 0.11.2：统一透明度与篮子图标

- 顶栏依次为图标、预览 Prompt、复制 Prompt、剪贴板暂停/继续、清空；清空同时移除指令和附件，可一步撤销。
- 指令框默认一行，换行或折行时自动增高；长文本在框内滚动。
- 附件每行两个，空位显示大“+”，填满后自动新增一行。
- 平时不显示导入色块；拖文件到某个添加位时，该位置才显示绿色副本、蓝色链接。
- 悬浮入口、菜单栏与应用图标统一为多份文件装进篮子的矢量图。
- 每个气泡内部独立呈现无色玻璃质感，附件区与顶栏使用相同透明度，没有连接气泡的底框、彩色边缘或外扩光晕；macOS 26+ 使用原生 Liquid Glass，旧系统回退透明材质。

## 完整 Prompt 与附件一起复制

- 有附件时，“复制完整 Prompt”一次复制 `PROMPT.txt` 和全部附件副本；到 Agent 中粘贴一次。只有文字时直接复制文字。
- Prompt 只保留任务、附件名称与说明；收集的文字和可读取文本文件的正文原样保留。
- 副本不显示路径和类型，不添加使用约定；源地址材料保留原文件路径。
- 添加、删除材料或修改任务、说明时自动更新 Prompt。
- 顶栏“预览”和“复制”分别预览、复制完整 Prompt，两个按钮同样高亮，没有生成步骤或成功提示。
- 附件说明用成对引号、深蓝文字与浅蓝底展示；按 Return 完成，Shift+Return 换行；输入法组词时先确认候选。
- 图标点击展开，再点同一图标缩回；不自动收起，拖文件到图标仍展开。
- 自动收集识别本应用复制的 Prompt，避免把输出又收回来。

软件按固定结构组织用户原文，不调用模型、不摘要或改写内容，也不会把图片伪装成已经上传的附件。

## 使用

1. 在其他应用复制文字、图片、网址或文件，材料会自动加入。也可拖入：左侧绿色区域创建副本，右侧蓝色区域引用源文件。
2. 给需要的材料添加说明，在第二排输入框写任务。
3. 点击“预览完整 Prompt”检查内容，再点击“复制完整 Prompt”。
4. 到 Agent 的输入框粘贴并发送。

剪贴板自动收集默认开启，点击顶栏暂停/继续按钮控制，重启后记住选择。只收集新复制的内容，不补收启动或恢复前的剪贴板；标记为机密、临时或自动生成的内容不会收集。如果 macOS 询问剪贴板访问，需要允许后才能自动收集。

## 浮窗与材料

- 收起为 58 点图标，预览与复制在顶栏，输入框与附件区上下排列并统一为 460 点宽；展开后保持打开。
- 添加位显示大“+”、“把材料拖到这里”和材料类型说明；指令为空时显示“输入指令”。
- “+”合并添加文件、链接、主动粘贴、默认导入方式、撤销与退出；有可撤销内容时，“+”旁显示撤销按钮。顶栏“×”清空内容。
- 卡片点击预览，悬停显示说明与删除；源地址定位原件并打开系统快速预览，网址用浏览器打开。
- 指令框只接收文字，文件与图片拖入指令框直接忽略。
- 删除只处理应用自己的资产，不删除源文件，支持一步撤销。
- 单张卡片仍保留独立拖出的辅助能力；主交付方式为复制完整 Prompt。

## 构建

运行需要 macOS 14+；构建需要含 macOS 26+ SDK 的 Apple 开发工具，产物使用本机 CPU 架构。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
open "dist/context basket.app"
```

使用本机临时签名。正式 Developer ID 签名、公证、跨机器分发和许可证尚未完成。

## 数据与边界

材料、说明、任务与自动收集开关保存在 `Application Support/ContextBasket`，旧格式自动迁移。副本单文件上限 100 MB；文件夹可作为源地址引用。网址只保留链接，不主动下载网页。

`exports/<UUID>/` 保存复制与单卡拖出的独立快照，暂不自动清理，删除材料后仍可粘贴先前复制的内容。复制本身不联网，附件在接收端粘贴后由接收端处理。系统截图的独立收集入口尚未实现。

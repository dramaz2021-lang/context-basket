# 🧺 context basket

> **把散落各处的上下文装进一个篮子，一键交给 AI。**

写 Prompt 时，你是不是也常常这样：在浏览器复制一段文字，在 Finder 找一份文件，再截一张图，然后在聊天框里来回粘贴，生怕漏掉什么？

**context basket** 就是为此而生的原生 macOS 小浮窗。它安静地待在屏幕边上，帮你把文字、图片、链接和文件一件件收进篮子。你再写上一句任务，点一下“复制”，到 Agent 里粘贴一次，所有内容就整整齐齐送过去了。✨

---

## 💡 为什么你会喜欢它

- **📋 复制即收集**：在任何应用里复制文字、图片、网址或文件，材料就会自动进篮子，不用切换窗口。
- **🖱️ 拖进来就行**：把文件拖到添加位上。放到绿色区域会保存一份独立副本，放到蓝色区域只引用原文件路径。
- **📝 每份材料都能写说明**：告诉 AI “这份是参考”“重点看第三段”，让它一眼明白你的意图。
- **🚀 一键复制完整 Prompt**：任务、材料说明和全部附件副本一次复制，到 Agent 里只需要粘贴一次。
- **👀 随时预览**：任务和材料一变，完整 Prompt 就自动更新，发送前可以先看一眼。
- **🫧 轻盈的玻璃气泡**：平时只是一个 58 点的小图标，点一下展开，再点一下收起。macOS 26+ 使用原生 Liquid Glass。
- **↩️ 放心试，随时撤销**：删除和清空都能一步撤销，而且**永远不会删除你的源文件**。

## 🔒 原汁原味，本机处理

context basket **不调用任何模型**，不摘要、不改写、不揣测你的意图。它只按固定结构整理你的原文，然后原样交出去。

- 所有材料、说明和任务都保存在本机 `Application Support/ContextBasket`。
- 复制过程不联网；网址只保留链接，不会主动下载网页。
- 剪贴板自动收集可以随时在顶栏暂停或继续，重启后也会记住你的选择。
- 只收集新复制的内容，不会补收以前的剪贴板。带有机密、临时或自动生成标记的内容（例如密码管理器复制的密码）不会被收集。
- 不会把自己复制出去的 Prompt 又收回来。

## 🎬 四步上手

1. **收集**：在其他应用里复制内容，或者直接把文件拖进篮子。
2. **说明**：给需要的材料加一句用途说明，再在指令框写下你的任务。
3. **检查**：点击“预览”看看完整 Prompt 长什么样。
4. **交付**：点击“复制”，到 Agent 的输入框粘贴并发送。🎉

> 首次使用时，如果 macOS 询问剪贴板访问权限，请选择允许，自动收集才能工作。

## 🛠️ 从源码构建

运行需要 **macOS 14+**；构建需要带 **macOS 26+ SDK** 的 Apple 开发工具。

```sh
bash scripts/test.sh          # 运行自动检查
bash scripts/build-app.sh     # 构建应用
open "dist/context basket.app"
```

> 构建产物使用本机临时签名，只适合在本机运行，并且只支持本机的 CPU 架构。正式的 Developer ID 签名、公证和跨机器分发还在路上。

## 📦 一些细节

- 复制完整 Prompt 时：有附件就复制 `PROMPT.txt` 和全部附件副本，只有文字就直接复制文字。
- Prompt 里只保留任务、附件名称和说明。收集的文字和可读取文本文件的正文会原样写入。
- 引用源文件的材料会保留原路径，不会把原件当作附件交出去。
- 单个副本文件上限 100 MB；文件夹可以作为源地址引用。
- 每次复制都会在 `exports/<UUID>/` 生成独立快照。即使之后删除了材料，之前复制的内容仍然可以粘贴。这些快照暂时不会自动清理。
- 点击卡片可以预览材料。源地址材料会在 Finder 中定位原件并打开快速预览，网址会在浏览器中打开。
- “+”菜单里可以选择文件、添加链接、主动粘贴、设置默认导入方式、撤销和退出。
- 指令框只接收文字，拖进去的文件和图片会被忽略。
- 悬浮图标或菜单栏图标上右键（或 Control+点击），可以退出应用。

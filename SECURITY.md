# 安全策略 / Security Policy

**简体中文** | [English](#english)

context basket 会读取剪贴板并在本机保存材料，我们非常重视安全与隐私问题。

## 支持的版本

只有最新发布的版本会接收安全修复。

## 报告漏洞

**请不要通过公开 Issue 报告安全问题。**

请在本仓库的 **Security** 页面点击 **Report a vulnerability**，通过 GitHub 私密漏洞报告提交。请尽量附上：

- 受影响的版本和 macOS 版本
- 问题描述和潜在影响
- 复现步骤（请使用合成数据）

我们会尽快确认收到，并在修复发布前与你保持沟通。

---

## English

context basket reads the clipboard and stores materials locally, so we take security and privacy issues seriously.

### Supported versions

Only the latest release receives security fixes.

### Reporting a vulnerability

**Please do not report security issues through public issues.**

Use GitHub private vulnerability reporting: open this repository's **Security** tab and click **Report a vulnerability**. Please include, where possible:

- Affected app version and macOS version
- A description of the issue and its potential impact
- Steps to reproduce (using synthetic data)

We will acknowledge your report as soon as possible and keep you informed until a fix is released.
